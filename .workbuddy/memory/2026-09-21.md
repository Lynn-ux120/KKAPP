### 四个必须锁死的版本（原配置缺这些必挂）
1. `requirements = python3==3.10.13,pygame` —— p4a 的 pygame 配方是 **2.1.0**，只支持到 Python 3.10；
   而 p4a 现在默认 Python 已是 **3.14.2**。不锁死必挂。
2. `Cython<3.0` —— Cython 3.x 移除 `longintrepr.h`，会编崩 pygame/kivy 配方。
3. `android.api = 33` + `android.ndk = 25b` —— NDK r25b 最高只支持 API 33。
4. `android.accept_sdk_license = True` —— 否则 CI 卡在许可证确认直到超时。

### 推送踩坑（已解决，下次直接照做）
1. **Git Credential Manager 会拦截 URL 里内嵌的凭据**。
   `git push https://user:TOKEN@github.com/...` 会静默 exit 128 且**零输出**。
   解法：加 `-c credential.helper=` 禁用凭据管理器即可。
2. **schannel 报 `server closed abruptly (missing close_notify)`**
   解法：`git config --global http.postBuffer 524288000` + `http.sslBackend openssl`。
   （已在本机全局配置，大文件/大推送场景通用）
3. **修改 `.github/workflows/` 下的文件需要 token 带 `workflow` scope**，
   只给 `repo` 会被拒：
   `refusing to allow a Personal Access Token to create or update workflow ... without workflow scope`
4. PowerShell 里抓 git 原生命令的错误要用 `*>&1 | Out-File`；
   `2>&1` 和 `Start-Process -RedirectStandardError` 都抓不到。
5. `-u <带token的URL>` 会把 token 写进 `.git/config` 的 branch 段，
   推完必须：`git remote set-url origin <干净URL>` + `git branch --set-upstream-to=origin/main main`。
