### 推送踩坑（已解决，下次直接照做）
1. **Git Credential Manager 会拦截 URL 里内嵌的凭据**。
   `git push https://user:TOKEN@github.com/...` 会静默 exit 128 且**零输出**。
   解法：加 `-c credential.helper=` 禁用凭据管理器即可。
2. **schannel 报 `server closed abruptly (missing close_notify)`**
   解法：`git config --global http.postBuffer 524288000` + `http.sslBackend openssl`。
   （已在本机全局配置，大文件/大推送场景通用）
3. **修改 `.github/workflows/` 下的文件需要 token 带 `workflow` scope**，
   只给 `repo` 会被拒：
   `refusing to allow a Personal Access Token to create or update workflow ... without workflow scope`
4. PowerShell 里抓 git 原生命令的错误要用 `*>&1 | Out-File`；
   `2>&1` 和 `Start-Process -RedirectStandardError` 都抓不到。
5. `-u <带token的URL>` 会把 token 写进 `.git/config` 的 branch 段，
   推完必须：`git remote set-url origin <干净URL>` + `git branch --set-upstream-to=origin/main main`。

### 第 1 次云构建失败原因（已修）
```
[ERROR]: Build failed: python3 should have same version as hostpython3, 3.10.13 != 3.14.2
```
只锁了 `python3==3.10.13`，但 p4a 的 **hostpython3**（构建期 Python）仍走配方默认 3.14.2。
**必须两个一起锁**：
```
requirements = python3==3.10.13,hostpython3==3.10.13,pygame
```
（hostpython3 是 p4a 自动插入的依赖，显式写版本号即可覆盖默认。）

### 修复「手机界面太小」（commit aac67fd）
**根因**：逻辑画布固定 720×820（比例 0.88），远"方"于手机竖屏（0.43~0.56）。
SCALED 等比缩放后画面只占屏幕中间一条，上下大片黑边（1080×2400 上黑边占 49%）。

**解法**：启动时按屏幕比例动态加高逻辑画布 —— `HEIGHT = 720 * 屏幕高/屏幕宽`，
clamp 到 [820, 2000]。1080×2400 → 720×1600，比例与屏幕一致，黑边 0。

**必须同步做的两件事**（否则游戏会变形/变简单）：
1. `PLAYER_Y = HEIGHT - 180`（判定线贴底部，角色不飘到中间）
2. 障碍速度 + 跳跃高度按 `ratio = HEIGHT/820` 同比放大
   → 预警时间恒定 ≈3.2s，各机型难度漂移仅 3.3%

**两个坑**：
- 部分安卓设备把屏幕**报告成横屏**(2400×1080)，会让适配整个失效 → 统一按
  "短边为宽、长边为高"归一。
- 自适应若对桌面也生效，Windows dummy/真机会按 1024×768 算出 720×960 窗口，
  在 768 高的屏幕上溢出 → **只在 Android 启用**（`sys.getandroidapilevel` /
  `ANDROID_ARGUMENT`），桌面可用 `KK_FORCE_FIT=1` 强制预览。

**验证**：新增 `tools/test_screen_fit.py`，模拟 7 种机型（含横屏报告陷阱），
断言黑边 <8px 且难度漂移 <8%。全通过（黑边 0~1px）。
